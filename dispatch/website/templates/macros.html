{#- A raster image resized by Zola at build time, offered as a srcset so the browser fetches only what the frame needs. The candidates are every width in `widths` (ascending) the source can fill, plus the source's own width when it lies below the largest and is not one of them, so a source between two widths keeps its full resolution (1177 px: 336, 672, 1177) and nothing is ever upscaled. The original is not published — the converter keeps it in an unpublished folder of the build. #} {% macro raster(path, widths, sizes, alt="", lazy=true) %} {%- set meta = get_image_metadata(path=path) -%} {%- set top = [meta.width, widths | last] | sort | first -%} {%- set_global picked = [] -%} {%- set_global srcset = [] -%} {%- set_global src = "" -%} {%- for w in widths | concat(with=top) -%} {%- if w <= top and not w in picked -%} {%- set img = resize_image(path=path, width=w, op="fit_width", format="webp", quality=82) -%} {%- set_global picked = picked | concat(with=w) -%} {%- set_global srcset = srcset | concat(with=img.url ~ " " ~ w ~ "w") -%} {%- set_global src = img.url -%} {%- endif -%} {%- endfor -%} {%- endmacro raster %}
