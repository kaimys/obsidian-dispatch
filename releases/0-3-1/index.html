2026-09-28 · GitHub release

A fix for 0.3.0#

Dispatch 0.3.1 fixes the 0.3.0 release, which shipped with the wrong manifest.json and was broken. The plugin's code, styles and minAppVersion are the same as in 0.3.0, so everything 0.3.0 introduced is in this version: github.com/kaimys/obsidian-dispatch/releases/tag/0.3.0

No migration and no configuration change.

Full changelog: github.com/kaimys/obsidian-dispatch/compare/0.3.0...0.3.1
